# ScanFit Design System

## Product Goal
ScanFit must feel like a premium AI health analysis product for pet owners. The first paid moment should be a surprising, credible report experience rather than a simple form result.

## Screen Architecture
- Food analysis is the primary entry flow.
- Exercise prescription is a separate second flow.
- Do not mix exercise recommendations inside food analysis.
- Hide internal model names from customers. Use "AI 분석 엔진" or "AI 리포트" instead.

## Visual Language
- Use clinical trust plus futuristic AI visualization.
- Prefer dark 3D analysis canvases paired with clean white report cards.
- Use green for nutrition, blue for analysis, amber for caution.
- Show dense but readable infographics, not decorative filler.

## Components
- 3D nutrition core: dark holographic grid, orbital rings, energy-density core.
- Macro infographic: protein/fat/carb bars with numeric values.
- Weekly meal plan: seven premium tiles with meals, calories, and rationale.
- Exercise load map: 3D activity silhouette, joint load, weekly burn, intensity.
- Download reports as polished HTML reports.

## Copy Rules
- No "GPT-5.5" or raw implementation details in customer UI.
- Say "AI 실시간 분석", "AI 사료분석", "AI 운동처방".
- Make results feel accurate while clearly avoiding medical diagnosis claims.

## Conversion Rules
- Results must show: confidence, summary, 7-day plan, download button.
- Pricing should appear after users see report value.
- Buttons should be clear commands with icon support.
